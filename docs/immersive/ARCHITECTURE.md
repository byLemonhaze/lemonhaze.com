# Immersive viewing modes

The vanilla JavaScript/Vite application and existing Cloudflare Pages project remain in place. `/` and `/?view=explore` enter Explore; `/?view=gallery` and `/?view=website` make the other modes explicit. Existing collection, section and inscription paths retain their meanings. The `/explore` editorial alias still leads to Practice.

The initial document resolves viewing mode before first paint, using the same route precedence as the runtime, so Website does not flash before Explore. The mode switch keeps the same viewport coordinates across all three modes, including mobile.

## Roster and composition

`src/curation/selection.js` remains the selected-work source shared by Gallery’s Selected works and the Selected Work page. `model.js` indexes the assembled catalogue plus the existing print records. Collection parents stored under Provenance are assigned their introducing collection within the immersive index only; catalogue records and IDs are unchanged.

`roster.js` resolves the explicitly identified edition collections through their provenance to the original work. It does not filter the word “Edition” generally: distinct works such as Uncut Gem (Miami Edition - 1/1s) remain. Deprivation appears once. The four unpublished Colors placeholders and the ORDINALLY collaboration punch card are excluded from Explore. Current result: 1,414 works from 1,649 indexed records, after 230 edition copies, four placeholders and one punch card are removed.

`core-placements.json` preserves the artist-approved 158 central placements within radius 2,500, including Minute, papillon! and the original eight. `layout.js` builds the surrounding staggered field without overlap. Recent years precede older years radially, with series interleaved within a year. Two works each from Best Before and Manufactured sit near the core; their other works begin beyond radius 2,200. Wu Wei, Ikigai and Lagom are explicitly separated under Chrysalis. All 25 Gentlemen stay within half the outer radius. Core placement exceptions take priority over chronology. Dark Horse has no special repositioning rule.

## Images and live artwork

`preview-manifest.json` indexes verified local WebP derivatives in `public/previews/immersive/`. `scripts/build_immersive_previews.mjs` builds them using Sharp from existing images and public render-service snapshots; originals are never modified. HTML artwork previews now prefer the artist’s static image before a render-service snapshot, avoiding captured controls and page backgrounds. `--refresh-name=Paint Engine` rebuilds matching derivatives; all Paint Engine thumbnails have been refreshed. Snapshot-only transparent padding is removed. The ratio repair pass prefers the original image source where catalogue dimensions and the first snapshot differ. Display follows actual image proportions rather than forcing metadata dimensions over an image. Best Before’s sealed/expired cards can legitimately be square while opened artwork is portrait.

Explore assigns image sources only within the viewport and its nearby margin, and releases sources outside it. Every visible item is eligible: there is no fixed 64-image ceiling. Thus the full overview eventually renders all 1,414 actual previews rather than leaving permanent empty slots. The derivatives total about 20 MB on disk; ordinary arrival loads only nearby works. Image dimensions are independent of resolution, so a small preview occupies the approved presentation size.

Explore uses small thumbnails in the overview and upgrades works displayed larger than 180 pixels. Gallery prioritizes the current work, then its visible neighbours, for sharp static previews. `media.js` limits each active view to two concurrent upgrades, decodes offscreen and swaps atomically, with cancellation and source checks to prevent late loads from replacing another work. Leaving a view clears its queue. Live media belongs to the solo detail view. Thumbnail-rail outlines follow the native image proportions while their transparent hit areas remain generous.

`live-document.js` fetches HTML from the inscription URL and mounts it in an opaque sandbox. A token-scoped first-paint bridge waits for visible canvas/WebGL, decoded image, SVG or video content before the poster is hidden. Relative asset/fetch URLs retain the chain base. Known Best Before self-identity is preserved; unknown location-dependent documents fall back to the static poster, with the original inscription link still available. The artwork itself is not stored or modified on-chain. Timeout, fetch failure, selection change and document hiding release the live context. Cross-origin dependencies may still be unavailable, so the static fallback remains essential.

## Explore motion

`field-physics.js` bounds the whole field as one group once it fits in the viewport. Edge impacts retain 86% of incoming velocity and can squash the whole field by up to 30%. An underdamped spring produces an expressive rebound and short settling wobble. Per-axis expansion is capped by the available screen space, so the full deformed field stays contained. Overview inertia lasts longer; close-up panning keeps its previous damping. The unbounded grab position is retained independently of the clamped camera. Its distance beyond the resting wall sets a sustained compression target while held, with the contact edge pinned to the wall. More pressure increases compression; release converts the stored pressure into inward rebound and restores the undistorted shape. Passive bounds corrections do not inject deformation energy. Bounds include the deformation and reserve space for navigation and controls. Close-up panning and all authored placements remain unchanged. Reduced motion removes bounce and deformation. Explore no longer shows the bottom-left label or motion toggle; device reduced-motion settings remain respected. The minimum pinch/button zoom adapts to narrow viewports so zoom-out still works below the mobile overview size.

## Gallery

The curated sequence remains one option alongside all catalogue collection groups. In the chooser, Selected works is followed by pinned Gentlemen, Impossible Folds prints, Montreal and BEST BEFORE; remaining collections run newest to oldest by year and collection date. Edition groups resolve to their originals. `collections.js` supplies the quiet searchable chooser with work counts, keyboard navigation and a mobile layout. A new collection selected from the chooser enters at its midpoint; subsequent visits restore that collection’s position. Entering Gallery from an open artwork split instead chooses that artwork’s own collection and centers the selected work. Both the Gallery mode tab (including an already-active Gallery tab) and “View collection in Gallery” use this contextual entry. The URL uses `series` and `at`, without `work`, so the split closes and Back restores it. Selected works retains its authored starting entry.

`gallery.js` renders only the neighbouring three to six images. The room background stays stationary while artwork mounts travel through virtual circular slots. The old end wall and giant travelling wall layers are removed, preventing hard seams at later entries. Previous/Next, keyboard, wheel and drag wrap in either direction; saved positions normalize to collection indices. The keyboard handler works from footer controls as well as the viewport and is suspended in details or the collection chooser. The camera translates the current work to the origin before applying motion tilt; rotating the uncentred world would make later entries disappear into depth. Home/End jump immediately rather than animating through hundreds of works. Both wheel axes and pointer drags navigate. Wheel gestures retain their dominant axis until settling. A frame-rate-independent critically damped motion model provides a restrained glide and snap, with reduced camera tilt and depth motion. The collection trigger contains only the current collection name and chevron. The artwork planes use native image proportions and minimal frames, with sufficient clearance above the floor.

## Shared artwork detail

`detail.js` is the detail experience for Explore, Gallery and Website artwork routes. The left side contains the selected work and collection rail; the right side contains its title, work-specific reflection (then description/about/collection fallback), year, format/dimensions/tools where provided, collection entry and original inscription link. “Full details & sales” mounts the existing metadata renderer inside the split, retaining inscription details, ownership, provenance, artist notes and sales. Async records are scoped to that container and selection token; switching works disposes the previous request context. Prints link to the Print Shop. There is no companion artwork or duplicated image. Mobile puts metadata beneath the artwork, with a 28 px visible close square inside a 44 px touch target, outside the scrolling panel.

Only the selected original runs. There is no per-artwork pause button; the shared reduced-motion preference still controls live playback. `presentation.js` fits each native artwork ratio inside an equal-width external mat. The first-paint bridge uniformly fits the visible live drawing surface to the same bounds, avoiding the inscription’s own internal margins being added a second time. Preview-to-original upgrades and transition flights preserve image proportions. Rapid selection removes obsolete posters and cancels prior flights; stale callbacks cannot replace the new work. The underlying scene is hidden/inert while detail is open. Focus returns to its opener where possible, and the persistent view switch remains reachable.

## Website and routing

Website home is a studio index with an existing print-table photograph and immediate links to Selected Work, Practice, About and Exhibitions. All Works, Studio Notes, Collecting, Print Shop and Lab remain below the index. Its old autoplay carousel is no longer mounted. At the artist’s request, the repeated “A continuous practice.” heading and eight-work grid were removed from the entry; both remain intact on Selected Work. The “Lemonhaze · 2023–2026” entry label is also removed. A single persistent `#site-wordmark` matches Explore/Gallery typography and position in every mode. A single Menu control opens a right-hand navigation drawer on desktop and mobile, replacing the permanent sidebar. Its All Works + disclosure restores the original expandable year groups and collection links, ending with Visual chronology; the separate searchable All Works page remains linked from the landing. It remains available on Website artwork details and closes after navigation. The drawer supports Escape, a keyboard focus loop, focus restoration, an inactive closed state and current-page indication. Its control stays outside page headers and the artwork background so it remains accessible. The destination pages’ existing copy is unchanged. Existing Selected Work, Practice, About, Exhibitions & Press, All Works, Studio Notes, Collecting, Print Shop and Lab sections remain available.

`/all-works` is a searchable collection directory grouped by year, with 53 public collections and a link to the existing visual chronology. Search matches collection names, years and individual artwork titles, ignoring accents and case. Matching titles show individual artwork image-and-title cards linked into the shared detail view. Collection covers sample up to three actual artworks, excluding parent records and known collection leads when alternatives exist. Collection cards retain existing collection URLs. Unpublished Colors placeholders are excluded. Destination page copy is unchanged. Landing links use the shared Website router without a document reload; a short opacity transition applies to page content while the wordmark and mode controls remain fixed. Reduced motion skips that transition.

`modes.js` integrates the existing router. `work=<id>` identifies immersive detail; Gallery uses `series=<collection>` and replace-only `at=<id>` for browsing. Opening/closing detail, collection changes and mode switches create history entries. Per-view camera and per-collection positions live in `history.state`, never a permanent mode preference.

The Website tab always routes to `/?view=website`, clearing artwork context. Website artwork URLs keep their canonical inscription paths but render the shared metadata split. Closing returns to the prior Website page and scroll position, or home for a direct arrival. Switching an edition into Explore uses its original representative; excluded punch cards cannot become contextual canvas additions.

The existing prerenderer records the new detail layout, releases its live frames, strips hidden immersive scenes from artwork captures, and normalizes temporary local image URLs to deployable paths. Existing search metadata and collection/artwork route coverage remain intact.
