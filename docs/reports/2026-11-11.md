# Work report — November 11, 2026

Today’s work replaced the former landing experience with a connected Explore / Gallery / Website system, then refined it through the artist’s live feedback. Existing content, artwork identities, aspect ratios and editorial destinations were preserved; approved exceptions include the new Gentleman Nº1 master-parent note and presentation/media changes.

## Delivered

- **Explore:** 1,414 original works; protected central composition; separated Chrysalis trio; Gentlemen in the inner half; Hosoi placement; lemon outline; wall squeeze/rebound; smoother desktop re-grabbing. Mobile starts zoomed out and uses one overview image before loading closer artworks.
- **Gallery and detail:** collection switching, remembered/midpoint entry, infinite scrolling, centre snapping, corrected arrows, native proportions, consistent frames, sharper images and live-media handoff. Split view now shows artwork plus information and full sales access. Clicking the artwork on desktop opens solo; close/Escape returns to the same split.
- **Navigation:** stable wordmark and mode switch; rapid-switch cancellation; Gallery/detail → Explore focuses the same work in the field; detail → Gallery retains its collection; Website opens its own home.
- **Website and archive:** coherent Menu drawer, independently scrolling All Works years, no repeated landing/Selected Work introduction, more contextual Studio Notes/Collecting media, and no duplicate note preview when expanded. The Hosoi signing segment autoplays without cropping or removing its watermark.
- **Catalogue:** collection-first search with actual artwork results, explicit cover selections, five Ethereum releases verified from lemonhaze.eth, edition deduplication, and removal of the public Provenance collection while keeping lineage records.
- **Reliability:** native pixel originals, sharper Manufactured/Old-Fashioned/Griffintown stills, bounded image upgrades, mobile pinch isolated from browser zoom, theme-flash fixes, and Catalogue iframe allowlisting. No catalogue.gallery files changed.
